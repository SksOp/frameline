Read `design.md` before changing user-facing UI. Trial 3 regenerates the full shadcn catalog, but an unmarked primitive is not approved for application use: migrate all of its states and dependencies first, then add `// DESIGN SYSTEM: Migrated to the current design.md.` as the first line. Browser E2E is deferred for this trial; preserve unit coverage and runtime invariants.

Use components over reusable CSS: reuse an approved `src/components/ui` primitive first, keep static token-backed Tailwind utilities and finite variants in the owning component, and extract repeated domain structure into a feature component. Do not add feature stylesheets, CSS Modules, reusable feature selectors, undiscoverable dynamic class-name fragments (including constructed fragments such as `state-${value}`), or static inline styles. Reserve `src/app/globals.css` for framework/theme imports, tokens, resets, document-wide accessibility behavior, and documented runtime keyframes. Inline styles are allowed only for runtime-calculated or user-selected values owned by that component. Next.js `ImageResponse` social artwork is also exempt because it cannot consume the CSS theme; keep recurring social colors in a typed TypeScript palette synchronized with CSS tokens.
